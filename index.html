🥗 一、馬拉松跑者日常整體飲食架構

🍚
三大營養素黃金配比
打底高耐力引擎與肌肉合成
碳水 55-65%
肌醣原主要燃料：每公斤體重 5~7g。首選地瓜、燕麥、糙米、蕎麥麵、義大利麵等優質複合碳水。
蛋白 1.5-1.8g/kg
修復肌纖維微撕裂：以 70kg 跑者為例每日需約 110-125g 蛋白質（雞胸肉、鮭魚、雞蛋、毛豆、無糖豆漿）。
好脂肪 20-25%
荷爾蒙平衡與關節抗發炎：特級初榨橄欖油、酪梨、原味綜合堅果、深海魚油 (Omega-3)。
💧
水分與電解質動態平衡
避免隱性脫水引發心率漂移與抽筋
基礎水
每日基本飲水量：體重 (kg) × 35~40 ml。例如 70kg 跑者非訓練日約需 2500~2800ml 純水。
補償水
流汗補償公式：跑後量體重，每流失 1kg 需在 2~3 小時內分次補足 1.25L 含鈉電解質水分。
自檢
尿液顏色自檢法：晨起尿液呈「清澈淡檸檬色」代表水分充足；若呈深黃色代表已處於脫水狀態。
🔬
防傷必備關鍵微量元素
提升血紅素攜氧與神經肌肉傳導
鐵質 + 葉酸
防止運動型溶血性貧血：紅肉、蛤蜊、深綠蔬菜。搭配維生素 C 水果（奇異果、芭樂）促進吸收。
鎂 + 鈣
肌肉放鬆與防夜間抽筋：睡前補充 200-300mg 檸檬酸鎂或吃一把南瓜籽、香蕉，能加深睡眠品質與神經舒緩。
維生素 D3
維持骨質剛性與免疫力：晨間適度日曬或補充 D3 滴劑，降低疲勞性骨折風險。

⏱️ 二、四大特定課表日專屬飲食時程表

🍃
輕鬆跑 / 恢復跑 (Easy / Recovery)
強度 Z1~Z2 • 促進脂肪燃燒代謝與微血管循環
跑前
空腹或極輕碳水：早起晨跑可喝 200ml 溫水或吃半根香蕉 (50-80 kcal)。低胰島素狀態有助於訓練粒線體利用脂肪酸。
跑中
僅需常溫水：時長在 40-50 分鐘內，僅需備清水潤喉，無需任何能量膠或高糖運動飲料。
跑後
抗發炎均衡正餐：正常享用一頓富含抗氧化物的正餐（如蛋餅 + 無糖豆漿，或烤鮭魚 + 菠菜 + 糙米飯）。
⚡
間歇跑 / 速度跑 (Intervals / VO2Max)
強度 Z4~Z5 • 高度依賴糖酵解供能與爆發力
跑前 2-3h
中低纖維高碳水：白米飯/白吐司/去皮地瓜。嚴禁高油炸與大量粗纖維生菜，避免劇烈衝刺引發胃痛或胃食道逆流。
跑前 30m
高 GI 快速供能：半包威德能量凍或半條能量膠，讓血糖飽滿、大腦神經處於高度敏銳狀態。
跑後 30m
黃金高蛋白+碳水：乳清蛋白 25g + 香蕉 1 根（碳水:蛋白質 3:1），迅速中斷肌肉分解 (Catabolism)。
🔥
節奏跑 / 門檻跑 (Tempo / Lactate Threshold)
強度 Z3~Z4 • 考驗血糖平穩輸出與抗乳酸能力
跑前 1.5h
平穩慢速碳水：原味貝果一顆、燕麥粥或蒸地瓜，提供平穩穩定的葡萄糖流，支撐 20-40 分鐘 T 配速。
跑中
低滲透壓電解質水：若里程達 8~10K，折返點可補充少量含鈉運動飲料，降低核心體溫上升速度。
跑後
乳酸排除與抗氧化：補充電解質水，並攝取富含花青素的藍莓、甜菜根或柑橘類水果，加速清除自由基。
🏔️
週末耐力長跑 (LSD 12~18km)
半馬成敗核心 • 實戰演練賽日補膠與肝醣儲備
跑前晚
前一晚肝醣超補：高碳水晚餐（義大利麵或白飯加大），少油炸，多喝水，把肌醣原與肝醣原填滿 100%。
跑前 2h
賽日模擬早餐：白饅頭夾蛋或花生醬吐司 1~2 片 + 香蕉 1 根 + 溫開水 300ml（可加黑咖啡促進排便）。
跑中實戰
定時吞膠＋補水：第 45-50 分鐘吞第 1 包膠配 150ml 水；超過 14K 在第 85 分鐘吞第 2 包膠。每 2.5K 抿水。
跑後修復
黃金液態補給 + 豐盛正餐：跑完 30 分鐘內喝光 400ml 巧克力牛奶或豆漿；2 小時內吃大碗牛肉麵或鮭魚定食。

⚡ 三、半馬正式賽日能量膠與進站實戰

⚡
半馬 21K 能量膠進站精準時程表

• 起跑前 20 分鐘：吞下第 1 包能量膠 ＋ 喝 150ml 水，讓血糖在鳴槍起跑時處於飽和充盈狀態。

• 第 7 ~ 8 公里 (約 45-50 分鐘)：吞第 2 包能量膠（進站前 100 公尺撕開吞下，進站順便喝 2 口清水漱口，不卡喉嚨）。

• 第 14 ~ 15 公里 (約 90 分鐘)：吞第 3 包能量膠（關鍵救命膠！即時拯救後半程大腦中樞神經糖份，維持 6'15"~6'30" 配速不掉速）。

• 水站原則：逢站必進，每次抿 1~2 口水潤喉即可，切忌大口暴飲造成胃部晃動脹氣。

👟
賽前裝備與防摩擦清單

• 跑鞋：使用已經磨合至少 50 公里以上的熟悉跑鞋，賽日絕對不穿全新鞋！

• 防磨保護：胸前乳頭貼（防汗水摩擦出血）、胯下與大腿內側塗凡士林或防磨膏。

• 雨備保暖（台北馬必備）：超商輕便雨衣一件（起跑前保暖防風，起跑後丟入大會回收箱）。

• 號碼布與晶片：賽前一晚先別在跑衣上，確保鞋帶晶片綁牢。

防摩擦、保暖與穿搭清單

⌚ Apple Watch 如何 0 秒自動同步到 Strava？

  1. 打開 iPhone 上的 Strava App。
  2. 點擊右下角「你 (You)」➔ 右上角「⚙️ 設定」。
  3. 點選「應用程式、服務與裝置 (Applications, Services, and Devices)」。
  4. 點選「健康 (Health)」，開啟「傳送到健康」以及「從健康讀取（自動同步體能訓練）」。
  5. 完成！以後每次在 Apple Watch 使用內建「體能訓練」或 Nike Run Club 跑完步，iPhone 會自動秒傳進 Strava，再透過本網頁一鍵同步即可！
